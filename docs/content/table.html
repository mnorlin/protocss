    Clean styling of the <table> element with support for row links.

    Simple table

    This is the basic style of <table>.

    Alice Smith 42
    Bob Johnson 53
    Eve Brown 25
    Mean age 40

    Table with row links

    If a row header cell contains a link, the framework automatically makes the whole row clickable.

    First name Last name Age
    Alice Smith 42
    Bob Johnson 53
    Eve Brown 25

    Advanced table

    A more complex table that shows

    • table caption, <caption>
    • column sorting, aria-sort="descending"
    • grouping of rows, scope="colgroup"
