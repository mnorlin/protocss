    • Configuration

    ProtoCSS is primarily configured using CSS variables, allowing the framework to be tailored to specific project requirements.

    Global tokens

    Global tokens define the primitive values of the ProtoCSS variable system and act as the source of truth for all other tokens. Updating a token such as --color-primary automatically generates a predefined set of six color shades used throughout the system.

    Derived tokens

    Derived tokens are automatically generated from Global tokens and represent computed values such as shades or contrasts. These tokens are not intended to be modified directly.

    Alias tokens

    Alias tokens assign semantic roles to Global and Derived tokens and are reused across components for consistent styling. For example, --color-border defines the color used for all borders in ProtoCSS.
